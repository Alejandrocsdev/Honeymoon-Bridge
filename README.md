# Honeymoon Bridge (Browser Card Game)

A complete browser-based implementation of **Honeymoon Bridge** built with plain **HTML, CSS, and JavaScript**.

This early project was created as a learning exercise to practice game logic, UI interaction, and API integration.  
The game uses the public Deck of Cards API to simulate real card dealing.

---

## 🃏 About Honeymoon Bridge

Honeymoon Bridge is a simplified two-player version of Contract Bridge, typically played by partners.  
This project simulates a single-player experience against a computer opponent.

---

## ✨ Features

- Fully playable Honeymoon Bridge game in the browser
- Uses https://deckofcardsapi.com for card generation and shuffling
- Rock‑paper‑scissors to determine who starts
- Bidding phase implementation
- Card exchange phase (first rounds)
- Final play phase until game end
- Trump logic included
- Automatic sorting of player’s hand
- Turn‑based gameplay flow
- No external frameworks — pure vanilla JavaScript

---

## 🤖 Computer Opponent

- Opponent logic is intentionally simple
- Moves are selected randomly
- Designed as a functional placeholder AI
- Focus of the project is game mechanics, not AI strength

---

## 🎮 Gameplay Flow

1. Start the game
2. Play rock‑paper‑scissors to determine starting player
3. Bidding phase
4. Card exchange phase
5. Final play rounds
6. Score / outcome
